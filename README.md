## Назначение файлов проекта

* **`main.c`** — демонстрационная программа со структурой `Item` (`id`, `name`, `quantity`, `price`) и функцией `cost(Item x)`, вычисляющей общую стоимость товара без сохранения её в отдельном поле.
* **`self.c`** — самостоятельная работа со структурой `Rectangle` (`width`, `height`) и отдельными функциями `area` и `perimeter` с проверкой корректности ввода и диапазона `1..1000`.
* **`tests.txt`** — протокол обязательных и собственных граничных тестов, включая пошаговую трассировку переменных для демонстрационной программы.

## Ограничения входа

* В `self.c` вводятся два целых числа (`width` и `height`) в диапазоне от `1` до `1000` включительно.
* При нечисловом вводе выводится `Input error`, при выходе за границы `1..1000` — `Range error`.
* Вычисляемые величины (стоимость, площадь, периметр) не хранятся в полях структур, чтобы избежать рассинхронизации данных при изменении размеров или количества.

## Команды сборки (PowerShell / Bash)

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o lab18
gcc -std=c11 -Wall -Wextra -Wpedantic self.c -o self
```
