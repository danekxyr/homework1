## Краткое описание программы

Консольная программа на языке С (стандарт C11) для ввода, статистической обработки и фильтрации одномерного массива целых чисел. Программа разделена на отдельные функции без использования глобальных переменных и корректно обрабатывает ошибочные входные данные.

## Описание входных данных

1. **Размер массива (`size`)** — целое число типа `int` в диапазоне от `1` до `100` включительно.
2. **Элементы массива (`array`)** — `size` целых чисел типа `int`, вводимых с клавиатуры.
3. **Границы диапазона (`a`, `b`)** — два целых числа типа `int`, где левая граница не превышает правую (`a <= b`).

## Перечень реализованных функций

* `int inputArray(int array[], int size)` — чтение элементов массива с клавиатуры с проверкой типа ввода.
* `void printArray(const int array[], int size)` — вывод исходного массива в одну строку.
* `int findMin(const int array[], int size)` — поиск минимального элемента и его первого индекса.
* `int findMax(const int array[], int size)` — поиск максимального элемента и его первого индекса.
* `long long calculateSum(const int array[], int size)` — вычисление суммы элементов массива.
* `double calculateAverage(const int array[], int size)` — вычисление среднего арифметического.
* `void countSignElements(const int array[], int size, int *pos, int *neg, int *zero)` — подсчёт положительных, отрицательных и нулевых элементов.
* `void countParityElements(const int array[], int size, int *even, int *odd)` — подсчёт чётных и нечётных элементов.
* `void printElementsInRange(const int array[], int size, int a, int b)` — вывод элементов, принадлежащих диапазону `[a, b]`.
* `void printLocalMaxima(const int array[], int size)` — индивидуальное задание (вариант 3): вывод элементов, строго больших обоих своих соседей (первый и последний элементы не учитываются).
